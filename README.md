# Velora
In this step-by-step tutorial, we’ll build Velora, an AI image and video studio, from scratch with Claude Code and the YouCam API. We’ll start with a cinematic Three.js landing page where an astronaut changes outfits as you scroll. Then we’ll build a virtual fitting room where you can try that idea with your own photos.
